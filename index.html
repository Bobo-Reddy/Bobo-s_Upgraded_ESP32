Mobile network bands

Read this before locking

Normally the node's modem chooses the mobile band by itself. Locking makes it use only the bands you tick.

  • Locking helps when one band is poor at a site and another is good. Run a band test first to see which bands work there.
  • Locking doesn't help when every band is poor, for example in a shielded spot or during a network outage.
  • If the locked bands stop working, the node removes the lock by itself within about 15 minutes and goes back to automatic.
  • The modem remembers the lock. Restore automatic clears it.
  • 4G only stops the modem dropping to slower 3G or 2G networks.
  • A node that can't get online won't see a change until it's back online, or until you switch it off and on.
  • The networks listed under each band own that band. It doesn't mean the band is switched on near the node. The band test shows what actually works there.
